# CSCS 模擬考練習工具 — 使用說明

## 開始使用
雙擊 `tools\practice-tool.html`，用 Chrome/Edge 開啟即可。完全離線，不需網路、不需安裝。
题目與解析存在 `tools\bank-data.js`（由 `bank\merged.json` 產生）。

## 題庫內容（共 3205 題）
- 選擇題 1604 題（附正解與解析）；記憶卡片 1601 張（正面術語、背面答案）
- 題目保留英文原文（考試為英文）；每题皆附繁體中文解析
- 來源：liftaroo(854)、Brainscape(744)、Cram(594)、GitHub packman(481)、Quizlet(275)、Trainer Academy(100)、certprep(99，原生中文解析)、NSCA 官方樣本(54)、practicetestgeeks(4)。詳見 `raw_sources\SOURCES.md`
- 部分題目僅 3 個選項（liftaroo 原站設計）；nsca-vol1 為舊版考綱題目（標記 legacy），仍適合練習科学基礎

## 四種模式
1. **K書模式**：可依部分（科學基礎／實務應用）、題型、來源、章节篩選。開啟即时反饋後，答題立刻顯示對錯與中英文解析。卡片題翻看後自評「忘記／記得一點／記得」，內建 spaced-repetition 排程。
2. **錯題本**：答錯自動收錄，連對 2 次自動移出。
3. **模擬考試**：依 2025 年新考綱——科學基礎 80 題 90 分鐘、實務應用 110 題 150 分鐘（另可自訂題數時間）。計時到點自動交卷；可標記題目、答題卡跳題；交卷後顯示原始得分、70% 及格線、各領域／來源正確率與逐題複習。
4. **學習統計**：各領域、各章节正確率與考試紀錄。

進度存在瀏覽器 localStorage，關頁不遺失；但考試進行中重新整理會中斷（設計如此）。

## 真實考試须知
- 兩部分都要過（換算分 70）；可 30 天後重考
- 實務應用部分含 30-40 題影片/圖片題，本工具為純文字，請另用教材影片資源補充
- 考綱與配比出處：NSCA 官方 JTA 2025 / CSCS 考綱（2025-07-01 生效版）

## 更新題目
改 `bank\` 內來源檔或放新來源 → 依序跑 `tools\merge_bank.py`、`tools\apply_zh_patches.py`（如有新中文解析 patch）、`tools\make_bank_data.py`。
